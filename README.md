# focus-noise-dataset

Генератор датасета изображений **острой фокусировки вихревого пучка** с секторным препятствием и
искусственным шумом. Датасет предназначен для обучения классификатора, который по картине
интенсивности в фокусе определяет **модуль топологического заряда** вихря `|mVortex|`.

Физическая модель — интегралы Ричардса–Вольфа (дебаевское приближение) для пучка с круговой
поляризацией, сфокусированного апланатической линзой. Искажение вносится секторной диафрагмой:
из апертуры вырезается сектор шириной `delta` (интегрирование по азимуту идёт от `delta/2` до
`2π − delta/2`), из-за чего кольцо интенсивности становится несимметричным, а картина зависит от
заряда вихря.

Весь код написан на MATLAB.

## Структура проекта

```
focus-noise-dataset/
├── RichWolf.m                              базовый класс: параметры линзы, интенсивность, вектор Пойнтинга, графики
├── debay2DGeneral.m                        подынтегральные выражения Ричардса–Вольфа (наследует RichWolf)
├── circularPar.m                           пучок с круговой/линейной поляризацией и вихрем (наследует debay2DGeneral)
├── modiffigures.m                          оформление осей и фигуры для публикаций
├── modiflabels.m                           оформление подписей осей
├── main.m                                  расчёт и отображение одной картины в фокусе
├── generate_focus_noise_dataset.m          генерация зашумлённых изображений для ОДНОГО класса
├── generate_focus_noise_labeled_dataset.m  генерация датасета для всех классов |m| = 1..8 с подписями
├── generated_focus_noise_dataset/          старая версия датасета (классы по знаку m и delta)
└── generated_focus_noise_dataset_abs/      актуальный датасет: классы по |m| = 1..8
```

Иерархия классов:

```
RichWolf  →  debay2DGeneral  →  circularPar
```

## Требования

- MATLAB (проверялось на версиях с поддержкой `classdef`, `integral2`, `parfor`).
- **Parallel Computing Toolbox** — желателен: расчёт амплитуд в фокусе идёт в `parfor`.
  Без тулбокса `parfor` выполняется как обычный цикл, только медленнее.
- Другие тулбоксы не нужны: палитра viridis задана в коде.

Все скрипты запускаются **из корня проекта** (`pwd` используется для пути к датасету), чтобы
классы `RichWolf`, `debay2DGeneral`, `circularPar` были в path.

## Быстрый старт

```matlab
cd путь/к/focus-noise-dataset
main                                    % посмотреть одну картину интенсивности
generate_focus_noise_labeled_dataset    % сгенерировать весь датасет (8 классов × 100 изображений)
```

Расчёт одной картины 100×100 — это 3 × 10 000 двумерных интегралов, поэтому полный датасет
(8 классов × 2 знака × 2 значения `delta` = 32 расчёта поля) может считаться долго. Шум
накладывается уже на готовую картину, так что число изображений на время почти не влияет.

## Общие параметры модели

| Параметр          | Значение          | Смысл                                                         |
|-------------------|-------------------|---------------------------------------------------------------|
| `lambda`          | 0.633 мкм         | длина волны (He-Ne лазер)                                     |
| `NA`              | 0.95              | числовая апертура линзы                                       |
| `rMin`, `rMax`    | −1.0 … 1.0 мкм    | размер расчётной области в фокальной плоскости                |
| `discretization`  | 100               | число точек по каждой оси (картина 100×100)                   |
| поляризация       | `'right'`         | правая круговая                                               |
| `mVortex`         | ±1 … ±8           | топологический заряд вихря                                    |
| `delta`           | π/8 или π/16      | угловая ширина секторного препятствия                         |

## Описание скриптов

### `RichWolf.m` — базовый класс

Абстрактная основа для расчёта поля в фокусе по Ричардсу–Вольфу. Сам интегралы не считает —
методы `calcAmp*Focus` здесь пустые заглушки, их переопределяют наследники.

**Свойства**
- Физические константы: `lambda`, `kWave`, `refrMedia` (показатель преломления среды, по умолчанию 1),
  `z0` (импеданс свободного пространства).
- Линза: `NA`, `thetaMin`/`thetaMax` (полярные углы апертуры), `alphaMin`/`alphaMax` (азимутальные
  углы — через них задаётся секторная диафрагма), `apodizationType` (`'aplanatic'` или `'diffractive'`).
- Источник: `mode` (сейчас поддерживается только `'plane'` — однородная засветка).
- Расчётная область: `rMin`, `rMax`, `rNum`, `rCoord`, `zCross` (плоскость расчёта, 0 = фокус),
  `zMin`, `zMax`, `zNum`, `zCoord`.
- Результаты: амплитуды `ampE{x,y,z}Focus`, `ampH{x,y,z}Focus`, интенсивности `intE*Focus`,
  `intH*Focus`, `intensityFocus`, `intensityHFocus`, компоненты вектора Пойнтинга `p{x,y,z}Focus`.

**Методы**
- Сеттеры: `setNA`, `setThetaMin`, `setThetaMax`, `setRBorders`, `setZBorders`.
- Расчёт: `calcIntensityFocus` (|Ex|²+|Ey|²+|Ez|²), `calcIntensityHFocus`, `calcPoynting{X,Y,Z}Focus`.
  Методы ленивые: недостающие амплитуды досчитываются автоматически.
- Графики: `plotIntensityFocus`, `plotI{x,y,z}Focus`, `plotIntensityHFocus`, `plotI{x,y,z}HFocus`,
  `plotPoynting{,X,Y,Z}Focus`.
- Вспомогательные: `source` (амплитудный профиль пучка), `apodization` (функция аподизации линзы),
  статические `calcrpsi` (декартовы → полярные координаты), `typicalFigMod1D`, `typicalFigMod2D`
  (оформление графиков через `modiffigures` / `modiflabels`).

> Объекты — value-классы: каждый метод возвращает изменённую копию, поэтому вызывать нужно так:
> `obj = obj.calcIntensityFocus();`

### `debay2DGeneral.m` — подынтегральные выражения

Наследник `RichWolf`. Содержит подынтегральные функции интеграла Ричардса–Вольфа для произвольной
однородной поляризации, заданной коэффициентами Джонса `(a, b)`.

- Статические `mMatrixE{x,y,z}`, `mMatrixH{x,y,z}` — строки матрицы преобразования поляризации
  линзой.
- `underintE{x,y,z}`, `underintH{x,y,z}` — полное подынтегральное выражение для каждой компоненты.
- `underinteq` — общая часть: `sin θ · exp(ik(z cos θ + r sin θ cos(φ−ψ))) · T(θ) · L(θ,φ)`, где в
  `L` добавлен вихревой множитель `exp(i·mVortex·φ)` (спиральная фазовая пластинка).

Нормировочный множитель взят равным `−i` (в комментариях отмечено, что строго должно быть
`−i·f/λ`), поэтому интенсивность получается в относительных единицах.

### `circularPar.m` — пучок с заданной поляризацией и вихрем

Наследник `debay2DGeneral`; именно этот класс используется во всех скриптах.

```matlab
r2 = circularPar(lambda, NA, 'right');   % 'right' | 'left' | 'linear x' | 'linear y'
r2.mVortex  = 3;                         % топологический заряд
r2.alphaMin = delta/2;                   % секторная диафрагма
r2.alphaMax = 2*pi - delta/2;
r2 = r2.setRBorders(-1, 1, 100);
r2 = r2.calcIntensityFocus();            % результат в r2.intensityFocus (100×100)
```

- Свойства: `mVortex` (по умолчанию 0), коэффициенты поляризации `aCircE`, `bCircE`, `aCircH`, `bCircH`.
- `calcAmpE{x,y,z}Focus`, `calcAmpH{x,y,z}Focus` — расчёт амплитуд в поперечной плоскости через
  `integral2` по θ ∈ [thetaMin, thetaMax], φ ∈ [alphaMin, alphaMax], внешний цикл — `parfor`.
- `calcAmp*SecX` (сечение вдоль оси x) и `calcAmp*YZ` (продольная плоскость YZ) — **не рабочие** в
  текущем виде: они записывают в свойства `ampExSecX`, `ampExYZ` и т.п., которые не объявлены в
  `RichWolf`, и упадут с ошибкой. В генерации датасета не используются.

### `modiffigures.m` — оформление фигуры

`modiffigures(fig, axs, ...)` — задаёт шрифт Times New Roman 9 pt, толщину осей, малые деления и
размер для печати 8×6 см. Дополнительные опции:
- `'CO'` — курсив и десятичная запятая вместо точки в подписях делений;
- `'CO-bar'` — десятичная запятая на цветовой шкале;
- `'threeinrow'` — размер 5.3×4 см (три рисунка в ряд);
- `'mdpi'` — шрифт Palatino Linotype (стиль журналов MDPI).

Файл сохранён в кодировке Windows-1251 (русские комментарии), при открытии в редакторе с UTF-8
они отображаются некорректно.

### `modiflabels.m` — оформление подписей

`modiflabels(labels)` — Times New Roman, курсив, 9 pt для переданных объектов подписей осей.

### `main.m` — одиночный расчёт

Учебный/проверочный скрипт: считает и выводит картину интенсивности в фокусе для одной пары
параметров. Варьируемые параметры в начале файла:

```matlab
mVort = 5;     % ТЗ вихря, например −5, 5, 3
delta = pi/8;  % ширина препятствия, pi/8 или pi/16
```

Ничего не сохраняет, только строит график (`plotIntensityFocus`).

### `generate_focus_noise_dataset.m` — один класс

Генерирует `numImages` (по умолчанию 500) зашумлённых изображений для одного класса
`absM` (по умолчанию 5) при одном значении `delta` (по умолчанию π/8).

1. Считает две базовые картины — для `+absM` и `−absM`, нормирует каждую в [0, 1].
2. Чередует знаки, так что `+m` и `−m` представлены поровну.
3. Накладывает шум (см. ниже), переводит в RGB с палитрой viridis.
4. Сохраняет **без подписи**, исходного размера 100×100, в
   `generated_focus_noise_dataset/class_absM_<absM>/img_<NNNN>_m<±m>.png`.

### `generate_focus_noise_labeled_dataset.m` — полный датасет

Основной скрипт генерации. Перебирает:
- `absMList = 1:8` — классы;
- `signList = [1, -1]` — знак заряда (в класс не входит, оба знака объединены);
- `deltaList = [pi/8, pi/16]` — ширина препятствия;
- `numImagesPerVariant = 25` — изображений на каждую комбинацию (знак, delta).

Итого 2 × 2 × 25 = **100 изображений на класс**, 800 всего. Каждое изображение:
1. зашумляется функцией `addNoise`;
2. окрашивается палитрой viridis (`getViridisMap`);
3. получает подпись `|mVortex|=<m>` в левом нижнем углу (`addLabelToImage`, через невидимую фигуру
   и `getframe`, из-за этого итоговый размер — около 400×400 и зависит от экрана);
4. сохраняется как
   `generated_focus_noise_dataset/class_absM_<m>/img_<NNN>_m<±m>_delta_<pi8|pi16>.png`.

Знак заряда и `delta` остаются только в имени файла — для справки и возможного стратифицированного
разбиения на train/test.

**Модель шума** (одинаковая в обоих генераторах, параметры выбираются случайно для каждого
изображения):

| Шум                         | Параметр                         | Диапазон          |
|-----------------------------|----------------------------------|-------------------|
| аддитивный гауссов          | `sigmaGauss`                     | 0.005 … 0.06      |
| мультипликативный (спекл)   | `sigmaMult`                      | 0 … 0.08          |
| импульсный (соль/перец)     | `impulseProb`                    | 0.001 … 0.02      |

После наложения шума изображение снова нормируется и обрезается в [0, 1]. Генератор
инициализируется `rng('shuffle')`, поэтому каждый запуск даёт новый набор.

> **Важно:** оба генератора пишут в папку `generated_focus_noise_dataset/`, а актуальный
> закоммиченный датасет лежит в `generated_focus_noise_dataset_abs/`. После генерации папки
> `class_absM_*` нужно перенести вручную, иначе они смешаются со старыми классами `class_mVort_*`.
